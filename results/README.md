# Result artifacts

- `demo_raw_predictions.jsonl` contains every raw output for the committed demo
  test split. Its SHA256 is frozen in `data/demo/split_manifest.json`.
- `demo_dataset_validation.json` is produced by the strict dataset validator.
- `demo_evaluation.json` is generated by `scripts/score_predictions.py` after
  installing the locked environment.

The demo intentionally has no `natural` row: programmatically darkened or
copied synthetic footage is not natural degradation. Complete robustness
validation therefore belongs to the controlled full-data test partition.

Paper-scale result rows without matching raw predictions, checkpoint files, and
the full Surv-VAU split manifest are excluded. The demo artifacts test the code
interface only and are not paper evidence.
