# Result artifacts

- `paper_results.json` is the aggregate numerical transcription used by the
  LaTeX parity checker. It is not presented as a substitute for raw outputs.
- `demo_raw_predictions.jsonl` contains every raw output for the committed demo
  test split. Its SHA256 is frozen in `data/demo/split_manifest.json`.
- `demo_dataset_validation.json` is produced by the strict dataset validator.
- `demo_evaluation.json` is generated by `scripts/score_predictions.py` after
  installing the locked environment.

Paper-scale raw predictions, checkpoint files, and the full Surv-VAU split
manifest are not part of this core release. Consequently, the aggregate paper
JSON supports manuscript-to-repository transcription checks but not independent
rescoring of the paper tables.
